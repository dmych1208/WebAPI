## 总结

v1.0.0 版本所有测试通过，三大渠道 (DeepSeek/通义千问/豆包) 均已就绪。

### 已知限制

1. 仅支持 Windows 平台
2. 需要目标平台保持登录状态
3. 首次请求较慢（页面加载）
4. 通义千问/豆包需要切换到对应标签页触发 WebView2 初始化

## 当前架构

```
WebAPI (WPF Application, .NET 9)
├── MainWindow
│   └── TabControl
│       ├── ChannelPanel (DeepSeek, 端口 55555)
│       │   ├── WebView2 → chat.deepseek.com
│       │   ├── ChannelHttpServer → 流式SSE转发
│       │   └── DeepSeekAdapter (PoW支持)
│       ├── ChannelPanel (通义千问, 端口 56666)
│       │   ├── WebView2 → qianwen.aliyun.com
│       │   ├── ChannelHttpServer
│       │   └── QwenAdapter
│       └── ChannelPanel (豆包, 端口 55556)
│           ├── WebView2 → www.doubao.com
│           ├── ChannelHttpServer
│           └── DoubaoAdapter
```

### 流式管道架构
```
API请求 → ChannelHttpServer.HandleStreamResponseAsync()
         → ProcessPromptStreamFunc(prompt, streamCallback)
         → ChannelPanel.SendPromptStreamCoreAsync()
           → InjectAndSendPromptAsync() → WebView DOM注入
           → WebView 网络拦截 → WebMessage → CoreWebView2_WebMessageReceived
           → ProcessNetworkData() → ProcessSseData() → EnqueueChunk()
           → ConcurrentQueue + SemaphoreSlim
           → streamCallback(text, isDone) → SSE写入HTTP Response
```

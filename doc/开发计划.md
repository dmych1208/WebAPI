## Phase 0: 项目初始化与基础框架 (Day 1-2) ✅

### Day 1 — 项目创建与骨架搭建

- [x] **P0-001** 创建 .NET 9 WPF 项目 `WebAPI.sln`
  - 项目名：`WebAPI`
  - 目标框架：`net9.0-windows`
  - NuGet 引入：
    - `Microsoft.Web.WebView2` 1.0.2849.39
    - `Hardcodet.NotifyIcon.Wpf` 2.0.1
  - 使用内置 `System.Text.Json`

- [x] **P0-002** 搭建目录结构
  ```
  src/
  ├── WebAPI/           # 主程序
  │   ├── Controls/     # 自定义控件 (ChannelPanel 等)
  │   ├── Adapters/     # 适配器
  │   ├── Common/       # 公共组件
  │   └── Models/       # 数据模型
  ├── log/              # 日志目录 (gitignore)
  └── doc/              # 文档目录
  ```

- [x] **P0-003** 实现多标签页主窗口骨架
  - `MainWindow.xaml` — TabControl + 状态栏
  - TabItem 动态生成（从配置读取渠道列表）
  - 每个 TabItem 内容 = `ChannelPanel` UserControl
  - 标签样式：图标 + 名称 + 状态指示灯

- [x] **P0-004** 实现 ChannelPanel 控件布局
  - 左右分栏 Grid (3* : 320px)
  - 左侧：WebView2 占位区域 + 底部输入栏叠加层
  - 右侧：StackPanel 包含状态区/API区/模型列表/日志区/按钮区
  - 深色主题配色方案

- [x] **P0-005** 配置管理器 `ConfigManager.cs`
  - 读取 `config/settings.json`
  - 渠道列表解析为 `List<ChannelConfig>`
  - 配置变更监听（FileSystemWatcher 热重载）

### Day 2 — HTTP服务 + SSE解析 + 日志系统

- [x] **P0-006** 实现 `ChannelHttpServer.cs`
  - 基于 `HttpListener` 的异步HTTP服务器
  - CORS 头处理 (`Access-Control-Allow-Origin: *`)
  - OPTIONS 预检请求处理
  - 路由分发：`/v1/chat/completions`, `/v1/models`, `/health`, `/shutdown`
  - 每个渠道独立端口实例

- [x] **P0-007** 实现 `RequestParser.cs`
  - 解析 OpenAI 格式 JSON 请求体
  - 提取 model / messages (system+user) / stream / temperature / max_tokens
  - 合并 system prompt 为前缀

- [x] **P0-008** 实现 `ResponseConverter.cs`
  - 构建 OpenAI 兼容格式的响应JSON
  - 流式响应：SSE格式 (`data: {...}\n\n`)
  - 非流式响应：完整JSON对象
  - 生成唯一 `chatcmpl-xxx` ID
  - 时间戳字段填充

- [x] **P0-009** 实现 `SseParser.cs`
  - 原始SSE流 → 结构化事件
  - 处理 `event:` / `data:` 行
  - 内部消息过滤（status/token_usage/title/update_session/search_result）
  - content 字段提取（支持 v/content/delta/reasoning_content/output.text 多种字段名）
  - 递归解析嵌套 JSON
  - 缓冲区管理（处理不完整的行）

- [x] **P0-010** 实现 `LogManager.cs`
  - 输出到 `log/YYYY-MM-DD.log`
  - 格式：`[HH:mm:ss] [LEVEL] message`
  - 级别：DEBUG / INFO / WARN / ERROR
  - 控制台 + 文件双输出
  - 自动清理 >30天的旧日志
  - 线程安全

- [x] **P0-011** 定义 `IAdapter.cs` 接口
  - TargetUrl / PlatformId / Port / UserDataFolder / AvailableModels
  - GetNetworkInterceptorScript() / GetDomControlScript()
  - InjectPromptAsync()

- [x] **P0-012** 创建 `config/settings.json` 默认配置文件
  - 三个渠道的默认配置（DeepSeek/千问/豆包）
  - 端口、URL、模型列表

- [x] **P0-013** 创建 `.gitignore`

## 风险与依赖

| 风险 | 影响 | 应对措施 |
|------|------|---------|
| 目标网页DOM结构变更导致适配器失效 | 高 | 将JS脚本外置为可编辑文件，方便快速修复 |
| WebView2内存占用过高 | 中 | 提供"重启浏览器内核"按钮；定期清理 |
| 某平台反自动化检测 | 高 | 模拟真实用户行为间隔；设置合理User-Agent |
| .NET 9 Runtime 用户未安装 | 低 | 发布时选择 self-contained 模式 |
| 千问/豆包需要登录才能用 | 中 | UI上提示登录状态；首次引导登录 |

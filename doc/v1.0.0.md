# v1.0.0 - 初始版本

> 发布日期: 2026-05-27
> 最后更新: 2026-05-27

## 新增功能

### 核心功能
- ✅ 多标签页 UI 界面，支持 DeepSeek / 通义千问 / 豆包 三大渠道
- ✅ 每个渠道独立运行：独立端口、独立 WebView2 实例、独立 HTTP 服务
- ✅ OpenAI-Compatible API 接口 (`/v1/chat/completions`)
- ✅ 支持流式 (SSE) 和非流式响应
- ✅ WebView2 嵌入目标网页，保持登录状态

### UI 功能
- ✅ 左侧 WebView2 浏览器面板（65% 宽度）
- ✅ 右侧控制面板（API 信息 + 模型列表 + 实时日志 + 操作按钮）
- ✅ 渠道状态实时显示（运行中/已停止/错误）
- ✅ Base URL 和 API Key 一键复制
- ✅ 可用模型组合点击复制
- ✅ 实时日志窗口（Consolas 等宽字体，深色主题）
- ✅ 重启浏览器内核 / 停止 HTTP 服务 按钮
- ✅ 底部状态栏（服务状态 | 端口 | 请求计数 | 运行时间）

### DeepSeek 渠道
- ✅ 支持 4 种模式切换：标准对话 / 联网对话 / 深度思考(R1) / R1联网
- ✅ 深度思考 / 智能搜索 快捷切换按钮
- ✅ SSE 流拦截与转换
- ✅ 网络拦截脚本（fetch + XMLHttpRequest）
- ✅ DOM 操作脚本（自动定位输入框、发送消息）
- ✅ 默认监听端口: **55555**

### 通义千问渠道
- ✅ 千问加速 / 千问增强 / 千问旗舰 模型
- ✅ 完整的适配器实现（QwenAdapter）
- ✅ 默认监听端口: **56666**

### 豆包渠道
- ✅ 豆包 Pro / Lite / 角色扮演 模型
- ✅ 完整的适配器实现（DoubaoAdapter）
- ✅ 默认监听端口: **55556**

## 使用说明

### 编译运行
```bash
dotnet build WebAPI.sln
dotnet run --project src/WebAPI/WebAPI.csproj
```

### 测试 API
```bash
# 健康检查
curl http://127.0.0.1:55555/health

# DeepSeek 对话（流式）
curl -X POST http://127.0.0.1:55555/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"deepseek-chat","messages":[{"role":"user","content":"Hello"}],"stream":true}'

# 通义千问对话（非流式）
curl -X POST http://127.0.0.1:56666/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"qwen-turbo","messages":[{"role":"user","content":"你好"}],"stream":false}'
```

### Python SDK 使用
```python
from openai import OpenAI

# DeepSeek
client = OpenAI(api_key="sk-any", base_url="http://127.0.0.1:55555/v1")
resp = client.chat.completions.create(
    model="deepseek-chat",
    messages=[{"role": "user", "content": "解释量子计算"}],
    stream=True
)
for chunk in resp:
    if chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="")
```
